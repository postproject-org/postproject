traces below. ABI reachability is distinct from semantic correctness. Every
changed native family is marked as changed in 0.7 at ABI 51; prior release
eligibility is not inherited. C++ Result propagation retains its source
protocol, but this report grants no new compatibility promise.

The Kdenlive and Blender traces cover the shared-production workflow,
including its deliberate conflict/redecision path. The Manager trace covers
publishing; its historical label still identifies one test-host route. OBS
and Natron inputs are their normal real-host traces. Focused negative and
contract runs are separate evidence and do not add independent host counts.
