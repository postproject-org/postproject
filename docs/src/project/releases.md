# Releases and compatibility

These pages describe what each release delivered, how it was verified, and which compatibility promises apply. They are records: a report describes the release it belongs to and is not updated afterwards.

## Compatibility and process

- {doc}`/abi-policy` — the native compatibility contract, ownership rules, threading, and the history of C ABI versions.
- {doc}`/releasing` — how a release is prepared, verified, and tagged.
- {doc}`/roadmap` — the direction of upcoming releases.
